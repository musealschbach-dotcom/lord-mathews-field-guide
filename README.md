# Lord Mathew's Field Guide

Offline field guide for scale technicians: real manuals, tap-to-read Contents, and calibration walk-throughs read aloud in lord Mathew's voice.

**Get the app:** see [Releases](https://github.com/musealschbach-dotcom/lord-mathews-field-guide/releases) — download `LordMathewsFieldGuide-v65.apk` on the phone, open it, install. The shelf packs in the same release are the manual libraries the app downloads in-app.

Works fully offline after install. No account, no ads, no tracking.
